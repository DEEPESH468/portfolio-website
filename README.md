# Deepesh Kumar Singh — Portfolio

A small, static personal portfolio built with HTML, CSS, and JavaScript. It introduces the owner, lists skills and projects, and provides contact and profile links.

## Preview locally

Open `index.html` in a browser, or start a local server from this directory:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Project files

- `index.html` — page content and links
- `style.css` — layout, colors, and responsive styles
- `script.js` — behavior for the “Explore More” button
- `diag/` — system architecture image and its source script

To personalize the site, update the text and contact URLs in `index.html`, then adjust the appearance in `style.css` as needed. No build step or package installation is required.
